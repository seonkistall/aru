# 컨시어지 킷 (B0 — 수작업 판매로 수요 검증)

> 2026-07-08 office-hours 피벗의 **최우선 트랙**. 스캔은 훅, "구매 순간"이 상품.
> 이번 주 코드 열지 말고 **손으로 10명한테 팔고** 트래커 들고 다음 세션.
> 실행 지시: [`AUTOPILOT.md`](../AUTOPILOT.md) B0 · 상태: [`STATUS.md`](STATUS.md)

## 왜 (do things that don't scale)
자동화·제휴·앱 기능 추가 전에, 오너가 **직접** 소싱·주문·정산해서
**실결제 / 재구매 / 객단가 / 마진 / 반론**을 배운다. 인터뷰 구매의향
(10명 중 4~5명)은 관심이지 행동이 아니다 — 실제 돈이 오가야 검증된다.

## 시드 게이트 (통과 시 B3 제휴 착수)
- **결제전환 ≥ 3/10** (스캔한 10명 중 3명 이상 실결제)
- **재구매 ≥ 1** (2~4주 뒤 한 명이라도 다시 삼 — 리텐션 프록시)
- 미달 시: 반론 로그로 오퍼/타깃/가격 조정 후 다음 10명.

## 실행 흐름 (1인 컨시어지)
1. **대상 10명**: 외국인(EN/JA/ZH) K뷰티 관심자 또는 지인. v1.1 다국어판이라 링크만 보내면 읽힘.
2. **스캔 링크 전송**: https://aru-beauty.vercel.app/scan — 결과 화면 스샷/공유링크 받기.
3. **소싱**: 결과+설문 보고 오너가 직접 상품 고름(올리브영/브랜드몰). 추천은 앱 리포트 참고.
4. **주문 접수**: 카톡/DM으로 원하는 것 확정. 가격·배송 안내.
5. **구매·전달**: 오너가 대신 사서 전달하거나 구매 링크 제공. (아직 제휴 딥링크 없음 → 마진은 수기 계산.)
6. **정산**: 판매가 받고 트래커에 원가·마진 기록.
7. **재구매 확인**: 2~4주 뒤 "다시 살 생각 있냐" 물어봄 → 트래커 재구매 칸.
8. **기록**: 매 건 [`concierge-tracker.csv`](concierge-tracker.csv)에 즉시 입력. 특히 **안 산 사람의 이유(반론)**.

## 지표 정의 (다음 세션에 이 숫자 들고 옴)
| 지표 | 정의 |

| 결제전환 | 실결제 수 / 스캔한 10명 |
| AOV(객단가) | 판매가 평균 |
| 테이크마진 | (판매가 − 원가) 평균, 마진율 % |
| 재구매 | 2~4주 내 재구매 인원 |
| 반론 로그 | 안 산 이유 목록(가격/신뢰/배송/취향…) |
