# 30명 파일럿 참가자 킷

운영 런북은 `docs/pilot-ml-loop.md`. 이 문서는 **참가자에게 보여주는 안내문 초안 + 운영자 당일 체크리스트**다.

## 참가자 안내문 (초안 — 그대로 읽어주거나 카톡으로 전달)

> 안녕하세요! 피부 상태를 카메라로 읽고 화장품과 루틴을 추천해주는 앱 **아루(ARU)**를 만들고 있어요.
> 5분 정도, 셀피 스캔 2~3번과 짧은 확인을 부탁드려요.
>
> **무엇을 하나요?**
> 1. 제 폰(또는 본인 폰)으로 얼굴을 스캔해요 — 가이드에 맞추면 자동으로 찍혀요.
> 2. 결과가 실제 느낌과 비슷한지 "맞아요/조금 달라요"로 알려주세요.
> 3. 원하시면 추천 결과까지 구경하실 수 있어요.
>
> **사진은 어떻게 되나요?**
> - 기본 스캔은 **기기 안에서만** 처리되고 원본 사진은 저장하지 않아요.
> - 연구용으로 얼굴 주변 크롭을 저장하는 건 **별도 동의**를 주신 경우에만 해요.
>   동의하면 크롭이 연구 검토용으로만 쓰이고, 원할 때 언제든 삭제를 요청할 수 있어요.
> - 이건 의료 진단이 아니라 "보이는 피부 신호" 기반의 화장품 추천 참고예요.

## 운영자 당일 체크리스트 (참가자 1명당 ~5분)

1. `/pilot`에서 참가자 세션 생성 (P001부터 순서대로 — ID는 이름과 연결하지 않는다)
2. `/scan?staff=1` 진입 → 캡처 모드는 기본 **균형**
3. 구두로 안내문 읽기 → **동의 2종을 참가자가 직접 체크** (AI 분석 전송 / 학습 크롭 저장 — 각각 독립, 둘 다 거절해도 진행 가능)
4. 스캔 1회차: 자동촬영으로 진행 → 결과에서 "맞아요/조금 달라요" 피드백 + 트러블 흔적 체크(해당 시)
5. 스캔 2회차: 같은 조건 반복 (재현성 데이터 — 같은 사람 연속 스캔의 레벨 일치율 측정용)
6. 여유가 있으면 3회차: **조명을 바꿔서** (창가 ↔ 실내등) — 조명 민감도 데이터
7. 참가자 종료 후 `/ops`에서 라벨/크롭 카운트 증가 확인
8. 세션 종료 처리 → 다음 참가자

## 하루 마감 루틴

- `/ops`에서 라벨 JSONL·크롭 내보내기 (Supabase 미연결 동안은 수동 백업이 원본)
- 파일명에 날짜 포함해 보관: `gyeol-labels-YYYYMMDD.jsonl`
- 10명(라벨 ~20-30개) 도달 시: `python ml/calibrate.py <jsonl>` 첫 캘리브레이션 실행
