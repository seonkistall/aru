# Google Play 콘텐츠 등급 작업표

대상: ARU 아루 `1.1.0 (11000)`

## App category

- 제안 카테고리: Beauty
- 앱 유형: App
- 타깃 사용자: 일반 소비자. 어린이를 주 대상으로 설계하지 않음.
- 광고: 현재 앱 내 광고 SDK나 전면/배너 광고 없음.
- 사용자 생성 콘텐츠: 공개 게시, 댓글, 채팅, 사용자 간 공유 없음.
- 구매: 앱 안에서 결제하지 않음. 외부 판매처 검색 링크는 있을 수 있음.

## IARC questionnaire guidance

실제 현재 동작 기준으로 폭력, 공포, 성적 콘텐츠, 도박, 통제 물질, 욕설, 공개 위치 공유 항목은 “없음”으로 제안한다. 피부 사진은 사용자 자신이 선택적으로 촬영하며 공개 피드나 다른 사용자에게 노출되지 않는다.

ARU는 화장품 선택 참고 도구이고 의료기기 기능을 표방하지 않는다. 통증, 지속되는 염증, 갑작스러운 변화 문구는 안전 안내이며 특정 질환을 판정하거나 의료 서비스를 제공하지 않는다.

콘텐츠 등급은 Play Console 답변으로 Google/IARC가 산정하므로 등급 값을 미리 단정하지 않는다. 제출자는 생성된 등급 요약에서 앱 동작과 다른 항목이 없는지 확인한다.

## Owner checks

- [ ] Play Console의 타깃 연령과 가족 정책 범위를 확정
- [ ] 외부 판매처 링크를 디지털 상품 결제로 잘못 표시하지 않았는지 확인
- [ ] IARC 결과와 스토어 문구·스크린샷이 일치하는지 확인
- [ ] 국가별 배포 범위와 현지 화장품/건강 표현 규정 검토
