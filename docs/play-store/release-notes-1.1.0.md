# ARU 아루 1.1.0 release notes

## ko-KR

- 피부 영역의 밝기, 반사와 선명도를 확인하는 카메라 품질 안내를 개선했습니다.
- 카메라 없이 설문만으로 추천을 완료하는 경로를 더 분명하게 정리했습니다.
- 개인정보 화면에서 ARU 기기 데이터를 한 번에 삭제할 수 있습니다.
- 모바일 화면 안정성, 오프라인 자산, 오류 복구와 접근성을 다듬었습니다.

## en-US

- Improved camera guidance for skin-area lighting, glare, and sharpness.
- Made the camera-free survey route clearer throughout the flow.
- Added one place to delete all ARU data stored on the device.
- Polished mobile stability, offline assets, error recovery, and accessibility.
