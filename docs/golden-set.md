# 골든셋 프로토콜 (회귀 측정용 고정 이미지 세트)

목적: 특징 추출/임계값/모델을 바꿀 때마다 **같은 입력에 대한 판독이 어떻게 변했는지** 측정한다.
골든셋 없이 코드를 바꾸면 개선인지 퇴행인지 알 수 없다.

## 구성 (20~30장)

| 축 | 값 |
|---|---|
| 인물 | 동의한 내부 인원 3~5명 (톤 다양성 확보: 밝은/중간/어두운 최소 1명씩) |
| 조명 | 창가 자연광 / 실내등 / 역광-근접 3종 |
| 거리 | 가이드 정위치 / 약간 멀리 2종 |
| 디바이스 | iPhone + Android 최소 1대씩 |
| 특이 케이스 | 메이크업 1명, 안경 1명 포함 |

## 수집 규칙

- `/scan?staff=1` + 학습 크롭 저장 동의 → 크롭 내보내기로 확보
- **레포에 절대 커밋하지 않는다** (얼굴 이미지). 로컬 `ml/data/golden/` (gitignore 대상) + 오프머신 백업 1곳
- 파일명: `golden-{인물ID}-{조명}-{거리}-{디바이스}.jpg`
- 라벨: 운영자 2인 합의(불일치 시 제외), `golden-labels.jsonl`로 관리

## 사용 방법

1. 특징/임계값 변경 전: 현재 코드로 골든셋 전체 판독 → 결과 저장
2. 변경 후: 다시 판독 → 레벨 변화 diff (몇 장이 어느 방향으로 움직였나)
3. 판정: 라벨 일치율이 오르면 채택, 내리면 롤백

## 필요한 하네스 (백로그)

- [ ] 판독 결과 JSONL 저장 + 이전 실행과 diff 출력
